# GRIVZO — онлайн-меню

Статический сайт без сборки и зависимостей: откройте `index.html` в браузере
или загрузите папку на любой хостинг (GitHub Pages, Netlify, Vercel, обычный хостинг).

## Структура

```
index.html          разметка страницы
css/styles.css      стили (цвета — в начале файла, блок :root)
js/config.js        настройки: номер WhatsApp, филиалы, доставка, оплата, контакты
js/menu-data.js     меню: категории, товары, цены, фото
js/app.js           логика: каталог, поиск, корзина, оформление заказа
assets/logo.webp    логотип GRIVZO (оригинал, прозрачный фон)
```

## Первое, что нужно сделать

1. **Номер WhatsApp** — `js/config.js` → `whatsappPhone: "77011234567"` (только цифры).
   Пока поле пустое, заказ откроется в WhatsApp, но получателя клиент выберет сам.
2. **Адрес филиала** — `js/config.js` → `branches`. Можно добавить несколько филиалов.
3. **Фото блюд** — сейчас стоят временные фото из Unsplash. Положите свои фото в
   `assets/products/` и укажите путь в `img`, например `img: "assets/products/royal.webp"`.
   Лучше всего квадратные 800×800.

## Как добавить товар или поменять цену

Откройте `js/menu-data.js`. Каждый товар выглядит так:

```js
{ id: "cheese-beef", name: "Чизбургер говяжий", price: 1800,
  desc: "",
  img: "assets/products/cheese-beef.webp" },
```

* **Цена** — поменяйте число `price`.
* **Новый товар** — скопируйте строку, задайте новый уникальный `id`.
* **Скрыть товар** — добавьте `hidden: true`.
* **Метка** — `badge: "hit"` (Хит), `"new"` (Новинка), `"spicy"` (Острое).
* **Новая категория** — добавьте блок `{ id, title, items: [...] }`; поле `nav`
  выводит категорию ещё и в верхнее меню на компьютере.

Корзина хранится в браузере клиента и всегда пересчитывается по актуальным ценам из меню.
